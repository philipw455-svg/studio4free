# Sting (about 2 s)

Logo, one line, link, mascots. The shortest ad: a bumper or an end card.

- **Built from:** `template.html`, drawn by `studio/film.py` with Playwright at the output size, 30 fps.
- **Needs from the storyboard:** one frame with `words` (the line), `cta` (the link, from `profile.md`), `look`, and `cast` (any mascot name turns the lineup on).
- **Needs from the brain:** a current logo in `kit.md` (the file whose name has the look in it), the fonts, and a current `picture` item named "lineup" for the mascots.
- **Timing:** logo 0 to 0.45 s, line 0.25 to 0.7 s, link 0.5 to 0.9 s, mascots rise 0.35 to 0.95 s. `pace` stretches or shortens these.
- **Words** sit inside the Reels safe area. The mascots sit in the bottom band, where only pictures go.
- A new sting can be saved as the brand's new end card: add it to `kit.md` as a current `end card`.
