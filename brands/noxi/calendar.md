# Noxi: calendar

One date per line: `- YYYY-MM-DD · kind · what · keys: words that name it`.
Kinds: launch, event, holiday, night (a big going-out night), quiet (post nothing).
The brain check uses this file to catch a wrong date, a wrong weekday, a "coming soon" that posts after the day, and a post on a quiet day.
