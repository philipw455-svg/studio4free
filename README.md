## Projects

### [Orbie Studio](https://github.com/philipw455-svg/Orbie)

<img src="https://raw.githubusercontent.com/philipw455-svg/Orbie/main/build/guide/studio.jpg" width="720" alt="The Orbie Studio canvas with agent cards">

A Windows desktop app that runs a team of AI agents to build a Roblox game.

- Each agent is its own Claude Code session with its own job and memory.
- A visual canvas shows every agent, who gives work, and who checks it.
- The app updates itself from GitHub and checks each file with SHA-256.
- **Stack:** Electron, Node.js, xterm.js, node-pty, Claude Code.

### [talkback](https://github.com/philipw455-svg/talkback)

<img src="https://raw.githubusercontent.com/philipw455-svg/talkback/main/docs/screenshots/mock.png" width="720" alt="The talkback Mock Interview screen">

An open source AI practice partner for math and job interviews.

- Solves math problems step by step, including from a photo.
- Runs mock interviews from your resume and a job description.
- Transcribes live calls with Groq Whisper and suggests answers.
- Ships Windows and Mac builds through GitHub Actions.
- **Stack:** JavaScript, Electron, Claude API, OpenAI-compatible APIs, Groq Whisper.

### Noxi (private)

A private iPhone photo app for friend groups on nights out.

- Random two-minute photo prompts during the night.
- A morning recap of the night for each group.
- Live in TestFlight beta testing.
- **Stack:** Expo (React Native), TypeScript, Supabase, Expo push notifications.

The Noxi source code is private.
